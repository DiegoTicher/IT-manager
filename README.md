# IT Manager - Sistema de Gestao de TI

Sistema completo para gestao de ativos, licencas, planejamento financeiro e inventario.

## Frameworks e Normas

- ITIL 4 - CMDB / Configuration Items / Change Management
- ISO/IEC 19770 - Software Asset Management (SAM)
- ISO/IEC 27001 - Anexo A.8 (Gestao de Ativos)
- COBIT 2019 - Governanca e Planejamento Financeiro de TI

## Como Rodar

### Back-end

    cd backend
    pip install -r requirements.txt
    python app.py

API em http://localhost:5000/api/

### Front-end

    cd frontend
    npm install
    npm run dev

Front em http://localhost:5173
